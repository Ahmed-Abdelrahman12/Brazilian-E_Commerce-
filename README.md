# Brazilian-E_Commerce
Project Overview
This project analyzes the Brazilian Olist E-Commerce dataset using Microsoft Excel to uncover sales, customer, and logistics insights.

Tools Used
Microsoft Excel
Power Query
Power Pivot
Pivot Tables & Pivot Charts
Dashboards
Overview Dashboard
Customer Dashboard
Logistics Dashboard
Key KPIs
Total Revenue
Total Orders
Average Order Value (AOV)
Average Review Score
Freight % of Revenue
Repeat Purchase Rate
Key Insights
Sales peak during the middle of the year.
SP state generated the highest revenue.
Top 10 product categories accounted for most orders.
Customer satisfaction declined when delivery time exceeded about 21 days.
